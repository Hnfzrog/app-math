Panduan Instalasi

Memasang Aplikasi AppMath

Panduan langkah demi langkah untuk memasang aplikasi LMS Matematika di komputer Anda. Ditulis dengan bahasa sederhana — tidak perlu paham coding untuk mengikutinya.

± 30 menit Tanpa coding Semua alat gratis

Sebelum mulai

Siapkan empat hal berikut. Nomor 1 wajib; nomor 2–4 gratis dan hanya butuh daftar dengan email.

  • ✓ Komputer (Windows atau Mac)Yang bisa terhubung internet. Untuk mengelola aplikasi sehari-hari.
  • ✓ Akun Supabase — gratisTempat data aplikasi (guru, siswa, nilai, jadwal, foto) disimpan. Daftar di supabase.com.
  • ✓ Akun Google AI Studio — gratisUntuk fitur koreksi jawaban otomatis. Daftar di aistudio.google.com.
  • ✓ Akun Vercel — gratis, opsionalHanya kalau aplikasi ingin diakses lewat internet (bukan cuma di komputer sendiri).

Langkah pemasangan

Kerjakan berurutan dari langkah 1. Jangan loncat — setiap langkah bergantung pada langkah sebelumnya.

  1. 01

    Unduh kode aplikasi

    Minta file aplikasi kepada pengembang (biasanya berbentuk tautan GitHub). Unduh sebagai ZIP, lalu ekstrak ke folder yang mudah diingat, misalnya Dokumen/app-math.

    💡Jangan letakkan di folder yang sering dipindah atau dihapus. Folder ini akan jadi "rumah" aplikasi.
  2. 02

    Pasang Node.js

    Buka nodejs.org, unduh versi LTS (tombol kiri), lalu instal seperti aplikasi biasa (Next → Next → Finish).

    Untuk memastikan berhasil: buka Command Prompt (Windows) atau Terminal (Mac), ketik node -v lalu Enter. Kalau muncul angka versi (misalnya v20.x), berarti sudah berhasil.

  3. 03

    Buat proyek Supabase

    Masuk ke supabase.com/dashboard → klik New Project. Isi nama proyek dan password database (simpan password ini), pilih region Singapore agar cepat diakses dari Indonesia, lalu tunggu 1–2 menit.

  4. 04

    Siapkan database

    Ini bagian terpenting. Anda akan menerima satu file SQL dari pengembang (nama filenya bisa berbeda, misalnya database.sql).

    Di dashboard Supabase, buka menu SQL Editor → New Query. Buka file SQL tersebut, salin seluruh isinya, tempel ke SQL Editor, lalu klik Run.

    Kalau file SQL dipecah jadi beberapa bagian, jalankan berurutan dari atas ke bawah.

    ⚠️Jalankan seluruh isi file sekaligus tanpa terpotong — kalau sebagian tidak ikut, ada tabel yang tidak terbentuk.
  5. 05

    Buat tempat penyimpanan foto

    Di Supabase, buka menu Storage → New bucket. Isi nama persis: foto (huruf kecil semua), lalu aktifkan pilihan Public bucket. Klik Save.

    ⚠️Nama harus tepat foto. Kalau berbeda, foto profil dan lampiran tidak akan tampil.
  6. 06

    Ambil kunci AI

    Buka aistudio.google.com/apikey → Create API key → salin kuncinya (deretan huruf dan angka yang panjang). Simpan sementara di Notepad.

  7. 07

    Isi file pengaturan

    Ambil tiga kunci dari Supabase: buka Settings → API, catat Project URL, anon public key, dan service_role key.

    Di dalam folder aplikasi, buat file baru bernama .env.local (gunakan Notepad), lalu isi seperti ini — ganti bagian bertanda ... dengan kunci Anda:

    NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
GEMINI_API_KEY=...
    ⚠️Simpan dengan nama .env.local — bukan .env.local.txt. Di Windows, aktifkan dulu View → File name extensions agar terlihat.
    🔒File ini berisi kunci rahasia. Jangan dibagikan ke siapa pun dan jangan diunggah ke internet.
  8. 08

    Pasang dan jalankan

    Buka Command Prompt / Terminal, arahkan ke folder aplikasi, lalu jalankan dua perintah ini satu per satu (yang pertama butuh beberapa menit):

    npm install
npm run dev

    Setelah muncul tulisan Ready, buka browser dan akses http://localhost:3000.

  9. 09

    Masuk pertama kali

    Kalau Anda menjalankan akun contoh di langkah 4c, gunakan salah satu akun berikut (password: password123):

    PeranEmail
    Adminadmin@gmail.com
    Guruguru@gmail.com
    Siswasiswa@gmail.com
    ⚠️Segera ganti password bawaan setelah berhasil masuk — terutama akun admin.

    Belum ada akun? Masuk sebagai admin → menu Kelola User untuk membuat akun guru dan siswa (email dibuat otomatis oleh aplikasi).

  10. 10

    Online-kan lewat Vercel — opsional

    Agar aplikasi bisa dibuka dari mana saja (bukan hanya komputer Anda): unggah folder aplikasi ke GitHub, lalu di vercel.com klik Add New Project → pilih repositori tadi → isi keempat kunci dari langkah 7 di bagian Environment Variables → Deploy.

    Setelah selesai, Anda akan mendapat alamat website (misalnya appmath.vercel.app) yang bisa dibagikan ke guru dan siswa.

Kalau ada masalah

Sebagian besar kendala di awal pemasangan ada di daftar ini. Cari pesan error yang muncul, lalu ikuti solusinya.

Yang terjadiPenyebab & solusi
Tulisan "relation does not exist" atau data tidak mau muncul Database belum siap. Jalankan ulang file SQL dari Langkah 4 sampai selesai tanpa error.
"new row violates row-level security policy" Bagian aturan akses (RLS) di file SQL belum ikut jalan. Pastikan seluruh isi file SQL dijalankan, bukan sebagian.
Upload foto gagal atau foto tidak tampil Bucket penyimpanan belum benar. Cek langkah 5 — nama harus foto dan statusnya Public.
Koreksi jawaban otomatis error Kunci AI salah atau kosong. Periksa baris GEMINI_API_KEY di file .env.local, lalu jalankan ulang aplikasi.
Muncul peringatan "GPS Belum Diaktifkan" terus-menerus Browser memblokir akses lokasi. Klik ikon kunci/gembok di address bar → izinkan Location → klik "Coba Lagi".
"npm tidak dikenali" Node.js belum terpasang. Ulangi langkah 2, lalu tutup dan buka ulang Command Prompt / Terminal.

Catatan penting

📌Jangan hapus file .env.local. File itu memegang kunci akses ke database dan AI. Kalau hilang, aplikasi tidak bisa terhubung ke mana pun.
💾Cadangkan data secara berkala. Supabase menyediakan fitur backup otomatis di menu Database → Backups.
🌐Aplikasi ini berjalan di internet, jadi pastikan komputer yang menjalankannya tetap menyala selama masih dipakai (kecuali sudah dipasang di Vercel).
